# Product Catalog

Каталог товаров с поиском, фильтрацией, пагинацией и избранным на основе публичного API DummyJSON. Проект разработан в качестве решения тестового задания на позицию Frontend-разработчика.

## Реализовано

- Каталог товаров с отображением цен, скидок, рейтингов и остатков на складе.
- Поиск по названию с debounce 400 мс и мгновенным запросом при длине ввода, кратной 4 символам.
- Фильтрация по категориям и диапазону дат обновления (meta.updatedAt).
- Сортировка по цене, скидке, рейтингу и названию (asc / desc).
- Бесконечная пагинация (Infinite Scroll) порциями по 12 товаров через IntersectionObserver с дедупликацией.
- Синхронизация состояния фильтров с параметрами URL (поддержка истории браузера Back/Forward и сохранения ссылок).
- Страница товара (/products/:id) с фотогалереей, характеристиками, отзывами и возвратом к каталогу с сохранением фильтров.
- Избранное с сохранением списка идентификаторов в localStorage.
- Состояния загрузки (скелетоны), ошибок сети и отсутствия результатов поиска.

## Запуск проекта

Требования к окружению: Node.js 18+ и npm 9+.

Команды выполняются из папки product-catalog:

```bash
npm install
npm run dev       # запуск сервера разработки (http://localhost:5173/)
npm run build     # проверка типов (tsc -b) и production-сборка
npm run lint      # запуск линтера Oxlint
npm run preview   # локальный предпросмотр production-сборки
```

## Структура проекта

- `src/api` — RTK Query эндпоинты для работы с DummyJSON API.
- `src/app` — конфигурация Redux store и типизированные хуки.
- `src/components` — UI-компоненты: каталог, общие элементы интерфейса, карточки товаров и шапка.
- `src/features` — клиентская логика состояния (избранное с localStorage, хук синхронизации URL useCatalogFilters).
- `src/pages` — страницы приложения (каталог, детальная страница товара, избранное, 404).
- `src/router` — конфигурация маршрутизации React Router.
- `src/styles` — переменные палитры, адаптивные миксины и глобальный сброс стилей.
- `src/types` — модели данных и типы параметров запросов.
- `src/utils` — вспомогательные чистые функции (расчет скидок).

## API

Приложение использует REST API DummyJSON (https://dummyjson.com/docs/products).

Основные используемые endpoint'ы:
- GET /products — список товаров с пагинацией, поиском, сортировкой и фильтрацией по датам
- GET /products/:id — данные товара по идентификатору
- GET /products/search — поиск товаров
- GET /products/categories и GET /products/category-list — список категорий
- GET /products/category/:category — товары выбранной категории
- POST /products/add, PUT /products/:id, PATCH /products/:id, DELETE /products/:id — мутации данных

Операции изменения данных (POST, PUT, PATCH, DELETE) на стороне DummyJSON носят имитационный характер и не сохраняются в базе данных сервера.
