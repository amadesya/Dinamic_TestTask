# Product Catalog

Полнофункциональное Single Page Application (SPA) каталога товаров на базе **DummyJSON API**, разработанное в соответствии со стандартами коммерческой фронтенд-разработки.

Подробная документация проекта, архитектурное описание и инструкции по запуску доступны в основном [README.md репозитория](../README.md).

---

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (http://localhost:5173/)
npm run dev

# Проверка типов и production-сборка
npm run build

# Линтинг кода
npm run lint

# Локальный предпросмотр сборки
npm run preview
```
