# Product Catalog

Каталог товаров с поиском, фильтрацией, пагинацией и избранным на основе публичного API DummyJSON.

Полное описание проекта, список возможностей и архитектура приведены в [основном README.md](../README.md).

## Запуск

Требования к окружению: Node.js 18+ и npm 9+.

```bash
npm install
npm run dev       # запуск сервера разработки (http://localhost:5173/)
npm run build     # проверка типов (tsc -b) и production-сборка
npm run lint      # запуск линтера Oxlint
npm run preview   # локальный предпросмотр production-сборки
```
